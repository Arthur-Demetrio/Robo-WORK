# Robo-WORK

Projeto de desenvolvimento de um robô móvel
omnidirecional para navegação autônoma.

## Tecnologias
- ROS 2 Jazzy
- Arduino Mega 2560
- LiDAR
- BNO055
- Nav2
- SLAM Toolbox

## Objetivo
Desenvolver um robô capaz de mapear ambientes,
identificar obstáculos e navegar de forma autônoma.
